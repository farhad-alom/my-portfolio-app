# Run the Project Locally

### 1. Clone the repository

```bash
git clone https://github.com/farhad-alom/my-portfolio-app.git
```

Replace `my-portfolio-app` with your actual repository name.

### 2. Open the project folder

```bash
cd my-portfolio-app
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

Create a `.env/.env.local` file in the project root and add the EmailJS environment variables required by your application.

Use the variable names already configured in your project. Never commit private credentials or your `.env.local` file to GitHub.

### 5. Start the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
